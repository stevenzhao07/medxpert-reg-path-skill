# 注册路径选择器 · 中美欧三市场

> 输入：风险分类结论 + 目标市场 + 产品特性
> 输出：注册路径 + 主管机构 + 本地代理要求 + 材料清单 + 关键卡点

---

## 一、美国市场（FDA / CDRH）

### 路径总览

| 风险类 | 路径 | 主管 | US Agent要求 | 材料核心 |
|--------|------|------|-------------|---------|
| Class I（多数） | 510(k)豁免 + 登记列名 | FDA CDRH | **强制必须有** | Establishment Registration + Device Listing |
| Class I/II（需通告） | **510(k) 实质等同** | FDA CDRH | **强制必须有** | eSTAR全套 + Predicate实质等同论证 + 性能测试 |
| Class III（高风险） | **PMA 上市前批准** | FDA CDRH | **强制必须有** | PMA全套 + 临床试验数据 |
| 新类型中低风险 | **De Novo 分类请求** | FDA CDRH | **强制必须有** | 风险收益论证 + 特殊控制 |

### 关键卡点（2026年最新）

- **eSTAR强制**：510(k)/De Novo必须用eSTAR提交，当前版本7.0（v6.2已于2026-08-03退休）
- **QMSR**：2026-02-02生效，对齐ISO 13485:2016
- **列名与登记**：即使豁免510(k)，所有器械仍须年度登记+列名
- **Predicate Device**：必须找到合法上市的同品种比对器械，没有就转De Novo或PMA

### 路径判定决策树

```
有没有同类已上市产品（Predicate）？
├─ 有 → 差异大不大？
│   ├─ 不大 → 510(k)
│   └─ 大 → 差异是否影响安全有效性？
│       ├─ 不影响 → 510(k) + 差异论证
│       └─ 影响 → 转PMA
└─ 没有 → 产品是新类型但风险不高？
    ├─ 是 → De Novo
    └─ 否（高风险） → PMA
```

## 二、欧盟市场（MDR 2017/745）

### 路径总览

| 风险类 | 路径 | 机构 | EU Rep要求 | 材料核心 |
|--------|------|------|-----------|---------|
| Class I（非无菌/非测量） | **自我声明 + CE** | 制造商自担 | **强制必须有** | 技术文档(Annex II/III) + DoC |
| Class I（无菌/测量/可复用） | 公告机构介入 | Notified Body | **强制必须有** | 上述 + NB证书 |
| Class IIa / IIb | 公告机构合格评定 | NB (Annex IX/X) | **强制必须有** | 技术文档 + CER + NB审核 |
| Class III / IIb植入 | 公告机构合格评定（更严） | NB (Annex IX + 设计档案) | **强制必须有** | 上述 + 设计档案审查 + 临床调查 |

### 关键卡点（2026年最新）

- **EUDAMED**：2026-05-28起四模块强制，新器械上市前须先注册
- **NB排期**：公告机构产能紧张，排期长是周期主要瓶颈
- **SSCP上传责任转移**：2027-02-27前制造商须完成SSCP上传
- **AI Act双重合规**：含AI且Class IIa+的器械同时受AI Act约束，高风险义务2028-08-02适用

### 分类规则速查（MDR Annex VIII）

- Rule 1：外科侵入式 + 短期 → Class IIa
- Rule 6：全身循环/心脏直接接触 → Class III
- Rule 10：含软件 → 按软件作用分类
- Rule 11：释放药物 → Class III
- Rule 13：有源诊断/治疗 → Class IIa/IIb

## 三、中国市场（NMPA）

### 路径总览

| 风险类 | 路径 | 主管 | 境内代理人要求 | 材料核心 |
|--------|------|------|---------------|---------|
| Ⅰ类 | **备案** | 市级药监局 | 境外须指定境内代理人 | 备案表 + 产品技术要求 + 检验报告 |
| Ⅱ类 | **注册（省级审批）** | 省级药监局 | 境外须指定境内代理人 | 注册申请 + 综述/研究资料 + 临床评价 + 检验 |
| Ⅲ类 | **注册（国家级审批）** | NMPA / CMDE | 境外须指定境内代理人 | 同Ⅱ类，资料深度更高 |

### 关键卡点（2026年最新）

- **免临床目录**：现行2025年版（19号通告，1047项），旧2023版已过时
- **GMP 2025版**：2026-11-01起实施，生产体系新要求
- **UDI实施**：II类（含IVD）+ I类IVD 2027-06-01起；I类2029-06-01起
- **发补时限**：1年（自收到补正通知起），逾期视为撤回
