# 注册路径决策报告 · 提交前检查清单

> 生成完报告后，逐项打勾。任何P0项没打勾 = 报告不合格，不能交付。

---

## 🔴 P0级（必过，不过就返工）

- [ ] **分类结论明确**：没有"大概是二类"这种模糊表述，明确写了Class II / Ⅱ类 / Class IIa
- [ ] **挂了法规依据**：每个分类/路径结论后面都有具体法规条款或目录条目
- [ ] **标了置信度**：每个关键结论后面都有（确定/高概率/待确认）
- [ ] **回答了临床要求**：明确说了免临床/同品种比对/临床试验，三选一
- [ ] **列了P0级发补风险**：🔴 P0级缺陷一个都没漏
- [ ] **没编法规条款号**：不知道的就标"待确认"，没有瞎编
- [ ] **说了本地代理要求**：US Agent / EU Rep / 境内代理人，三选一或明确说不需要
- [ ] **没给精确报价**：只给区间，没有"正好XX万"这种精确数字

## 🟡 P1级（尽量过，缺了不致命但扣分）

- [ ] **列了备选路径**：不只给一条路，说了"如果推荐路径走不通，可以走什么"
- [ ] **P1级发补风险排序了**：按风险高低排，不是随便列
- [ ] **每条发补风险配了自查要点**：不只说"会发补"，还说了"提交前怎么检查"
- [ ] **列了关键时间节点**：比如FDA 510(k) RTA 60天 + SE 90天
- [ ] **给了下一步行动建议**：用户看完知道接下来该做什么
- [ ] **说了主要不确定性**：NB排期 / 临床数据 / 发补次数

## 🟢 P2级（加分项，有了更好）

- [ ] **附了免责声明**："本报告为AI辅助判定，正式申报前请与注册专员复核"
- [ ] **边界情况列了两种可能**：分类在边界上的，说了两种可能性+各自理由
- [ ] **对比了多市场差异**：如果用户问了多个市场，说了中美欧的路径差异
- [ ] **用了正确的专业术语**：没有把"实质等同"翻译成"实质相同"这种错译
