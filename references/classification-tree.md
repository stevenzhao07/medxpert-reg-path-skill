# 产品分类判定树 · 中美欧三市场

> 输入：产品7项基本信息 → 输出：风险分类 + 判定依据 + 置信度

---

## 必收7项信息（缺任何一项先问用户）

| # | 字段 | 说明 |
|---|------|------|
| 1 | 产品名称/通用名 | 用于比对分类目录 |
| 2 | 结构组成与材质 | 金属/高分子/生物材料/含药/含动物源 |
| 3 | 预期用途 | 诊断/治疗/监护/缓解/补偿/替代 |
| 4 | 接触部位与时长 | 表面/腔道/侵入/植入；暂时(<24h)/短期(24h-30d)/长期(>30d) |
| 5 | 是否无菌提供 | 是/否 |
| 6 | 是否重复使用 | 一次性/可重复使用 |
| 7 | 是否含软件/SaMD | 是/否（含则触发AI/SaMD分支） |

## STEP 0 · 特殊通道优先（命中即跳结论）

```
① 是否药械组合产品？
   ├─ 是 → 走药审中心/器审中心联合界定 → 跳出本树
   └─ 否 ↓

② 是否含动物源/人源/生物技术材料？
   ├─ 是 → 至少III类倾向 + 生物安全性专项 → 建议分类界定
   └─ 否 ↓

③ 是否独立软件（SaMD）？
   ├─ 是 → 走AI医疗器械分类指导原则
   │       辅助决策类多III类；非辅助决策类II类
   └─ 否 ↓

④ 是否IVD体外诊断试剂？
   ├─ 是 → 走IVD分类目录（本树不适用）
   └─ 否 ↓ 进入正常判定
```

## 一、中国 NMPA 分类规则

### 判定流程

```
产品在《医疗器械分类目录》内有明确条目？
   ├─ 有，且预期用途与目录完全一致 → 直接采用目录分类
   ├─ 有，但预期用途/结构有差异 → 差异影响风险？
   │   ├─ 影响 → 建议申请分类界定
   │   └─ 不影响 → 参考目录分类
   └─ 目录内无条目 → 按《分类规则》(15号令)判定
```

### 分类规则速查（15号令）

| 风险程度 | 分类 | 典型产品 |
|---------|------|---------|
| 低风险 | Ⅰ类 | 手术刀、镊子、绷带、压舌板 |
| 中度风险 | Ⅱ类 | 血压计、体温计、助听器、心电图机 |
| 高风险 | Ⅲ类 | 心脏支架、起搏器、人工关节、IVD诊断试剂 |

**关键升级因素**（命中至少一个，分类升级）：
- 无菌提供
- 重复使用
- 植入人体
- 长期接触（>30天）
- 含药/含动物源材料
- 辅助决策软件

## 二、美国 FDA 分类规则

### 判定流程

```
查FDA Product Code数据库，有没有对应产品代码？
   ├─ 有 → 看该Code的分类（Class I/II/III）
   └─ 没有 → 是否全新产品类型？
       ├─ 是 → De Novo路径
       └─ 否 → 找Predicate Device比对
```

### 分类速查

| Class | 风险 | 典型产品 | 上市前路径 |
|-------|------|---------|-----------|
| Class I | 低 | 手术刀、检查手套、压舌板 | 多数豁免510(k) |
| Class II | 中 | 血压计、输液泵、超声设备 | 510(k)实质等同 |
| Class III | 高 | 心脏起搏器、人工心脏、植入式除颤器 | PMA上市前批准 |

**FDA分类核心维度**：
1. 侵入程度（非侵入/外科侵入/植入）
2. 接触时长（暂时≤24h / 短期24h-30d / 长期>30d）
3. 接触部位（表面/腔道/循环系统/中枢神经系统）
4. 是否维持生命

## 三、欧盟 MDR 分类规则

### MDR Annex VIII 22条核心规则（速查Top10）

| Rule | 内容 | 分类结果 |
|------|------|---------|
| Rule 1 | 外科侵入式+短期使用 | Class IIa |
| Rule 5 | 一次性使用手术器械 | Class IIa |
| Rule 6 | 全身循环/心脏直接接触 | Class III |
| Rule 7 | 中枢神经系统直接接触 | Class III |
| Rule 8 | 释放能量类（有源治疗） | Class IIa/IIb |
| Rule 10 | 含软件 | 按软件作用分类 |
| Rule 11 | 释放药物物质 | Class III |
| Rule 13 | 有源诊断/监护设备 | Class IIa |
| Rule 14 | 用于避孕/性传播预防 | Class IIb |
| Rule 22 | 含纳米材料 | Class III |

### 分类原则（MDR核心）

**风险等级由低到高**：Class I → IIa → IIb → III

**升级规则**：一条器械命中多条Rule，取**最高风险等级**那条。
