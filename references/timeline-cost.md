# 周期费用测算模型 · 中美欧三市场

> 输入：市场 + 路径 → 输出：时间线 + 费用区间 + 关键里程碑
> ⚠️ 所有数字均为**行业区间参考，非实际报价**，最终以正式报价单为准。

---

## 一、中国 NMPA

| 路径 | 周期（自资料齐备起） | 费用区间（参考） | 关键里程碑 |
|------|-------------------|----------------|-----------|
| Ⅰ类备案 | 1-3 月 | 万级 | 备案提交 → 公示 |
| Ⅱ类注册（省局） | 6-12 月（含检验/临床评价） | 十万-数十万 | 检验 → 临床评价 → 体系核查 → 审评 → 发证 |
| Ⅲ类注册（国家局） | 12-24 月+ | 数十万-百万级 | 同上，资料深度更高 |

**关键影响因素**：
- 发补一次通常 +3-6 月
- 2026-11-01起 GMP 2025版影响体系核查准备时间
- 不含前期研发和产品开发时间

---

## 二、美国 FDA

| 路径 | 周期 | 费用区间（不含临床） | 关键里程碑 |
|------|------|-------------------|-----------|
| 510(k) | 3-9 月（含准备） | 中 | 比对论证 → 提交 → RTA审查 → 实质性审查 → 发函 |
| De Novo | 6-12 月 | 中-高 | 分类请求 → 审查 → 确立新分类 |
| PMA | 12-36 月+（含临床） | 百万级（含临床） | 临床 → 模块化递交 → FDA审查 → 批准 |
| 列名登记 | 1-2 月 | 低 | Establishment Registration + Device Listing |

**关键时间节点（FDA法定审查时限）**：
- 510(k)：RTA审查 60天 + 实质性审查 90天（共约6个月，实际常超期）
- US Agent年费 + FDA用户费（如适用）另计
- 临床是PMA周期/费用的最大变量

---

## 三、欧盟 MDR

| 路径 | 周期 | 费用区间（参考） | 关键里程碑 |
|------|------|----------------|-----------|
| Class I 自我声明 | 2-6 月 | 低-中 | 技术文档 → DoC → CE → EUDAMED录入 |
| Class IIa | 6-12 月 | 中 | NB申请 → 技术文档审核 → CE证书 |
| Class IIb | 9-18 月 | 中-高 | 上述 + 样品/体系审核 |
| Class III / IIb植入 | 12-24 月+ | 高 | 上述 + 设计档案审查 |

**最大不确定性**：公告机构(NB)排期
- MDR下NB产能紧张，排队常6-18个月，是欧盟周期主要瓶颈
- EUDAMED四模块2026-05-28起强制，注册前须先完成Actor/器械录入
