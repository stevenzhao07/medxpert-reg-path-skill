# 临床要求判定 · 中美欧三市场

> 输入：分类结论 + 产品特性 → 输出：临床路径（免临床/同品种比对/临床试验）
> 临床是注册里**最贵最慢最容易翻车**的一环，判定必须谨慎。

---

## 三条临床路径（三市场通用框架）

| 路径 | 说明 | 成本 | 周期 |
|------|------|------|------|
| **A · 免临床** | 有目录/规则支持，不需要新做临床 | 最低 | 最短 |
| **B · 同品种比对** | 用已上市同品种数据+差异论证，免新试验 | 中 | 中等 |
| **C · 临床试验** | 自己做临床实验，产生新数据 | 最高 | 最长 |

---

## 一、中国 NMPA

### 判定流程

```
是否列入《免于临床评价医疗器械目录》（2025版 · 1047项）？
   ├─ 是，且所有条件完全匹配 → 【路径A：免临床】
   ├─ 是，但适用范围有差异 → 差异小可论证免临床，差异大走比对
   └─ 否 → 能否找到同品种做比对？
       ├─ 能找到 + 临床数据可比 + 差异论证充分 → 【路径B：同品种临床评价】
       └─ 找不到/差异太大 → 【路径C：临床试验】
```

### 关键注意点

- **免临床目录现行版本**：2025年版（19号通告，2025-05-12施行），旧2023版已失效
- **同品种比对核心**：适用范围/技术特征/生物学特性/制造工艺 四方面实质等同，差异需补充数据论证
- **临床试验要求**：须先过伦理 + 临床备案/审批（GCP规范）

---

## 二、美国 FDA

### 判定流程

```
走510(k)路径？
   ├─ 是 → 有Predicate Device + 无重大差异？
   │   ├─ 是 → 【路径B：实质等同比对，通常免新临床】
   │   │       （用Predicate数据 + 自身bench test/生物相容性数据）
   │   └─ 否 → 【路径C：需临床试验支持510(k)或转PMA】
   │
   ├─ 走PMA路径 → 【路径C：临床试验（通常必需）】
   │
   └─ 豁免510(k) Class I → 一般不要求临床
```

### 关键注意点

- 美国没有中国式的"免临床目录"，"临床豁免"主要体现在510(k)下用Predicate比对
- PMA高风险器械：临床试验数据基本必需，是FDA注册最大成本项
- 真实世界数据(RWE)可作为补充，但不能完全替代临床试验

## 三、欧盟 MDR

### 判定流程

```
Class I 自我声明？
   ├─ 是 → 仍需Annex XIV临床评价（可用文献+等价器械数据）
   │       → 【路径B：CER，通常免新试验】
   │
   └─ Class IIa及以上 → 是否有足够临床证据？
       ├─ 有文献 + 等价器械数据充分 → 【路径B：CER】
       └─ 证据不足 → 【路径C：临床调查(Clinical Investigation)】
```

### 关键注意点

- MDR下**所有类别都需要临床评价**（即使Class I自我声明也需要写CER）
- 等价性论证是CER核心：必须证明和另一个器械在解剖/生理/技术特性上等价
- 高风险Class III/植入类：通常需要临床调查

## 输出格式要求

```markdown
### 临床要求判定结论

| 项 | 内容 |
|---|------|
| 产品 | [产品名称] |
| 目标市场 | [中国/美国/欧盟] |
| **临床路径** | [免临床 / 同品种比对 / 临床试验] |
| 判定依据 | [免临床目录第XXX项 / Predicate Device XXX / MDR Annex XIV] |
| 数据缺口 | [还缺什么临床数据] |
| 周期影响 | [临床阶段预估 X-Y 个月] |
| 置信度 | [确定 / 高概率 / 待确认] |
```

> ⚠️ 临床判定是注册里最容易翻车的地方。拿不准就标"待确认"，建议和临床评价顾问复核。
